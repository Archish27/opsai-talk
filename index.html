05 · GOVERNANCE
Humans have the final say

The "Red Switch."

OpsAI operates within boundaries you define. It suggests solutions, generates PRs, applies fixes only where you've granted permission. Developers review AI-written code before merge. Co-pilot SRE, not autonomous chaos.

01 · AUTO INVESTIGATION
Investigation runs automatically for every critical alert. You don't trigger it. It just happens.
02 · PICK & CHOOSE
Per-cluster, per-service settings. Production stays propose-only. Staging gets full Auto Fix.
03 · TOKEN CONTROL
Balance automation with resource caps. Settings let you cap how much the agent can spend.

The diff OpsAI opened.

― BEFOREflask/app.py:61-66 
- @app.route('/user/<username>')
- def user_profile(username):
-     user = user_data[username]

-         raise Exception("missing user")

+ AFTERflask/app.py:61-66 
+ @app.route('/user/<username>')
+ def user_profile(username):
+     if username not in user_data:
+         abort(404, description=f"user {username} not found")

Raw lookup gone. Unreachable if not user block stripped. Proper 404 instead of a 500. One file. Five lines. Reviewer-ready.
